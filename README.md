# VBST
A simple Binary Search Tree implementation that is built to handle any abstract data type that can be ordinated by numeric keys. It uses normal ints in the node keys, but this can be changed depending on the application.

## Usage
You can use it as a module for other projects or simply as a tree simulator with the GUI script. The tree runs entirely on RAM so if you need to store it on a persistent drive you'll need to do a function for that.

## GUI
If you use the function print_tree in your main, you can run the *automatic_gui_show.sh* script to open it on a PyGame GUI, which is very useful, but you should use print_tree only in the end of your code or change the way *automatic_gui_show.sh* script runs.
